# FSO Kaynakları

| Klasör | İçerik |
|---|---|
| `01_Kitaplar_Tezler_DersNotlari` | Kitaplar, doktora tezi, ders notları |
| `02_Survey_Genel_Bakis` | Survey ve genel bakış makaleleri |
| `03_Atmosfer_Turbulans` | Atmosferik türbülans ve kanal etkileri |
| `04_PAT_Isaretleme_Takip` | Pointing, Acquisition & Tracking |
| `05_Terminal_Verici_Test` | Terminal/verici tasarımı ve test sistemleri |
| `06_Terminal_Datasheetleri_Pazar` | Ticari terminal datasheet'leri ve pazar raporu |

Dosyaların orijinal konumları: `KAYNAK_LISTESI.txt`.
